CLI, Build & MCP Quickstart

Zero-friction local install on Windows, plus bundler-free WASM builds.

PowerShell -- Install & Run
# Install DJCraft Pro binaries + MCP config
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-craft.ps1

# Parallel 24-thread crate analysis (BPM, Camelot Key, Phrases)
djcraft-cli library analyze-crate --crate "Peak Hour"

# Export crate to AlphaTheta Rekordbox XML
djcraft-cli library export-rekordbox --crate "Peak Hour" --out rekordbox.xml
Build WASM & Preview Site
# Compile bundler-free WASM DSP engine
cargo build -p djcraft-wasm --target wasm32-unknown-unknown --release

# Stage wasm next to docs/site/index.html
copy target\wasm32-unknown-unknown\release\djcraft_wasm.wasm docs\site\

# Serve locally
uv run python -m http.server 8765 --directory docs\site
