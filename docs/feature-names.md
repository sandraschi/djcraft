## Factual Interoperability Statements (Permitted)

- **File formats:** `Import/Export Serato .crate` (UTF-16BE TLV), `Import/Export VirtualDJ .vdjfolder`, `M3U / M3U8`, `MP3 / WAV / FLAC / OGG / AAC / M4A`.
- **Hardware MIDI controllers:** `midir` auto-detection and mapping profiles for standard class-compliant DJ MIDI controllers.
