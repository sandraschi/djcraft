# `djcraft-audio` (L1 4-Deck Real-Time Audio & Stem DSP Engine)

100% Safe Rust real-time audio engine for **DJCraft Pro**:

- 4-deck playback with NCC keylock, vinyl scratch physics, DVS timecode probe, Auto-DJ transition planner, 3-pack FX racks, and 4x8 sampler.
- Stem-Aware Neural Crossfader (`FULL`, `VOC`, `DRM`, `BASS`, `INST`), master limiter with gain-reduction metering, dual-bus PFL cueing, and WAV/FLAC recording.
- SynthCraft Live Bridge (`DJLK`/`DJPD`/`DJFX` send + Aux Return on `:20811`) and 3-band RGB waveform extraction.
