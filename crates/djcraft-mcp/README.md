# `djcraft-mcp` (L2 Dual-Mode CLI & 46-Tool MCP Stdio Server)

Headless CLI (`djcraft-cli.exe`) and Model Context Protocol (`stdio`) server (`djcraft-mcp.exe`) exposing 46 tools over pure JSON-RPC on `stdout`: deck/mixer control, crate scanning & smart queries, ID3 batch read/write, Camelot transition planning, MIDI mapping, DVS/Link probes, Art-Net/sACN lighting, and setlist export.

```powershell
djcraft-mcp.exe
```
